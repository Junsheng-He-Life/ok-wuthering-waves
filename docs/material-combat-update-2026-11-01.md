# 材料识别、战斗保护与连续轮刷更新

本次更新源代码，不修改已发布的 `v0.1.0-beta.1` 下载附件。配套框架使用 `Junsheng-He-Life/ok-script` 提交 `dfed279`；底层已包含本地所需修改，本次无需再发布框架补丁。

## 材料计划

`CrossTeamMaterialTask` 读取保存队伍的实际三人，再逐个切换培养目标。材料卡片先检测图像边界、读取数量；名称由详情页核实后建立图标索引，不以第几行或角色等级判定材料已齐。共享材料库存只计一次，需求按目标汇总。

领奖后优先核对相关材料和共享奖励；冲突、库存下降、遗漏及需求变化回到全量扫描，局部刷新也有连续次数限制。未知材料、未适配路线和失败材料保留待办，不能作为完成项。

同次运行中，已经失败且完成退场恢复的材料按名称隔离，适用于不同角色的同名材料。其他关卡成功不清除隔离。重启时可用可重复的 `--defer-material 准确名称` 显式暂缓已诊断的失败项；该选项不减少需求或改动库存。

## 战斗执行

- 调度、动作确认、有界重试、生命保护和退场恢复共用；角色模块负责各自的前置条件、输入和视觉完成证据。
- `SkillAction` 区分已确认、不可用、未确认和中断。延迟冷却确认必须属于同一角色、同一驻场和新帧；不能用旧冷却、伤害数字或任意画面变化推断连招完成。
- `RotationSequence` 保存步骤进度，未确认的必要动作不推进，异常不会重播整套开场。变形、二段和长按机制仍需要专用观察器。
- 普攻先经过有界的首次健康/技能检查，再启动实际攻击窗口，避免短攻击段被首次识别完全耗尽。后续检查和输入均占用窗口；准备超时不补发。按次数定义的角色动作仍保留次数。
- 健康头像仅在身份匹配且画面新鲜时减少重复数字 OCR；低血量和治疗继续数值核对。受伤隔离不因时间经过而解除，必须有恢复证据；下一场重新核对队伍健康。
- 异常退出时恢复临时检查标志。角色 HUD 可见时仍检查生命，隐藏 HUD 保留动画容错。Boss 硬截止不能被血条可见无限延长，截止时先核对真实胜利。

## 日志和资源保护

材料窗口显示真实材料图标、缺口及滚动日志；向上回看时保持位置，“回到最新”恢复跟随。最近 5000 行保留在界面，完整日志仍在本机文件。窗口只读取文件，不启动游戏采集。

控制器锁、共享账本、待核对领奖和补给保护保持有效。溶剂与储备默认零，历史未知或消费结果未确认时禁止重复消费。真实补给来源与兑换预览、领奖前后余额和库存刷新分别留证。

高级 CLI 中，`--runs -1`、`--max-stamina -1`、`--reserve-limit -1` 分别取消本次对应额度上限；只能在使用者明确授权时设置。`--solvent-limit -1` 仅允许使用已配置的累计溶剂授权剩余额度，仍受 `--solvent-total` 和历史账本约束。其他账号不能照抄维护者的资源授权。

## 示例

使用相邻配套框架、Python 3.13 环境，从项目根目录运行。以下两份奖励/80 波片示例不允许补给：

```bash
PYTHONPATH=../ok-script:. .venv/bin/python scripts/ultrawide_trial.py \
  --phase plan --target-teams 1,2,3,4,5 --combat-teams 2,4,5 \
  --runs 2 --max-stamina 80 --reserve-limit 0 --solvent-limit 0 \
  --desktop-session --desktop-preflight --desktop-experimental \
  --record-hud --continuous --timeout 0
```

单角色可加 `--target 角色名`。`--desktop-level-advisory` 是显式实验选项，只跳过等级门槛，保留身份、血量、世界等级和消费保护。

## 声骸稳定性跟进

新增共享处理：声骸模式恢复健康头像快路径，仍周期核对数字HP；治疗验证跌至40%时停止站场等待，只有数字血量核对通过的健康队友才能接场，记录“治疗未确认、转交队友”，没有健康接场仍退场。首次普攻准备耗时与短输入窗口分开，保留失焦、暂停、手动退出及过期保护。

角色适配：卜灵的两种蓝色治疗重击图标与黄色伤害重击分开判定。未准备好的长按会损血，因此没有可见提示时不长按；治疗卦先于可能覆盖它的E/下落攻击处理，持有鼠标期间异常保证释放。今汐先读取已经返回的冷却证据，再处理重试超时，避免在截止时丢弃成功帧。这些修复不代表所有多段动作均已完成视觉适配。

导航补充：失败治疗停在地图时先正确退出地图；仅在明确地图页进行两次有界缩放重找真实信标。明亮天空背景的半透明大世界图标增加真实图像模板，位置和阈值保持不变，副本/领奖反例保持拒绝。
