# 0.1.0-beta.3

按角色培养增加所有目标角色共用的刷取项目多选。默认仅声骸、不领奖；未勾选项目不执行，推荐不明的声骸路线不替换。支持原生 App 启动、指定培养角色及共享资源预算，保留当前游戏编队、控制锁与消费账本。

声骸路线通过角色培养方案中的合鸣套装名称与无音区筛选栏核对，支持滚动的完整套装列表；不使用旧头像颜色判断。角色范围与选择框提供原生窗口快捷键，macOS 下为 Command-Option-T / 1、2、3，再用方向键选择。

治疗核验支持生命上限变化：必须同一伤员在两张新帧中确认新上限、数值与头像血条一致，再使用保守换算基准判断真实恢复。单纯增加上限、重复帧、近似头像读数和被拒绝 OCR 均不能证明回血；原护血阈值保留。

详见 [培养项目说明](cultivation-scope-2026-11-04.md) 和 [使用指南](beta-user-guide.md)。公开包补齐新模式代码、离线检查与文档，不含个人配置或账本。游戏指南的当前目标标记是推荐范围依据，不提供声骸主副词条毕业判定。

增加独立 Apple Silicon App：内置 Python 3.13、锁定依赖、OCR 模型和预编译原生 helper，无需 Python、Xcode、Terminal 或 Codex。个人配置、账本和待核对消费保存在 Application Support，替换 App 保留数据；运行中的旧窗口或控制器阻止源码升级。仅 ad-hoc 本地签名，未经过 Apple Developer ID 签名或公证。

二进制逐项验证 arm64、包内动态库依赖和 macOS 14 最低版本。OpenCC 1.2.0 使用同版本源码重新构建为 macOS 14 部署目标，配套 wheel 与 SHA256 一并发布，不修改开发者原虚拟环境。公开离线测试为108项应用检查、33项后端检查；原生权限探针1项明确排除。

源码修复的限额实测以玄翎／弗洛洛／穗穗完成心的沉心域和烬心域领奖。最终烬心域88.05秒获胜；未触发紧急治疗，因此生命上限变化分支的证据仍为离线回归。独立 App 只做无游戏离线验证，不表示所有角色、关卡或其他机器均已验收。
