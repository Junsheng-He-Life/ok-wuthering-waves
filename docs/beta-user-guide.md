# 0.1.0-beta.3 安装与使用

## 独立 App 安装（推荐）

下载 Release 附件 `OK-WW-macOS-arm64-0.1.0-beta.3.zip`，解压并将 **OK-WW 鸣潮助手.app** 拖到“应用程序”，双击打开。内置 Python、依赖、OCR 模型和预编译原生组件，不需要安装 Python、Xcode 或 Codex，也不需要 Terminal。

本版是 ad-hoc 本地签名，未获得 Apple Developer ID 签名和公证。下载后核对 Release 中的 SHA256；若系统拦截，到“系统设置 → 隐私与安全性”按系统提示使用“仍要打开”，不要全局关闭 Gatekeeper。首次连接游戏时，按诊断结果给实际显示的 OK-WW 运行宿主屏幕录制和辅助功能权限；修改后退出重开 App。不要给无关程序权限。

个人数据始终保存在 `~/Library/Application Support/OK-WW/ok-wuthering-waves`；启动错误见上级目录 `launcher.log`。只替换 App 即可升级；升级不会清空账号、账本或待核对消费，旧窗口或控制器仍在运行时会拒绝升级。打开 GUI 不开始任务，领奖默认关闭。

**旧源码版用户**：本版不会自动读取或迁移其他目录的账本。请保留旧安装并先核对历史和待核对消费，不要对同一账号勾选“全新安装”重建空账本。有未结清记录时先联系维护者处理。卸载 App 不会删除个人数据。

## 源码安装（开发者备用）

需要Apple Silicon Mac、macOS 14+与简体中文游戏。主要实测画面1920×1080，其他画面需单独验证。

1. 获取完整包`ok-ww-macos-beta-0.1.0-beta.3.zip`，解压到新目录。不要覆盖旧安装，不要分开移动两个项目。
2. 从[Python官网macOS下载页](https://www.python.org/downloads/macos/)安装**3.13系列**。安装[Apple命令行工具](https://developer.apple.com/xcode/resources/)：终端运行`xcode-select --install`并按提示完成。
3. 双击**安装与检查.command**。安装器核对发布文件，创建项目`.venv`，下载锁定依赖并诊断；不启动游戏或初始化账号记录。下载失败可保留目录重试。
4. 双击**启动.command**或生成的**OK-WW 鸣潮助手.app**。启动器借助Terminal打开GUI，不需要Codex；它不是签名/公证独立二进制，不自带Python。移动目录后重新运行安装入口生成启动器。
5. 若系统拦截，先核对下载来源与校验和，再使用系统的“仍要打开”流程，不要全局关闭系统保护。屏幕录制、辅助功能权限给实际运行宿主（通常是Terminal）；修改后可能需要退出重启。
6. 全新安装在“安装与使用”勾选确认后建立空白本地账本。检测到历史或待核对消费时不能清零；不要复制别人的configs、logs或虚拟环境。

安装失败输出保存在`ok-wuthering-waves/logs/installation.log`。GUI打不开时运行**环境诊断.command**；保留输出，提交前检查个人路径等信息。

## 选择副本与角色

先在游戏进入大世界、选好队伍，再点**读取当前队伍**。不读取角色等级；进场前控制器核对并治疗三人。游戏须保持前台，不要并行开第二个控制器。

- **无音区 / Boss**：点“读取关卡 / 材料需求”，从下拉列表选择。可见入口不表示全部Boss已适配，未知策略会停止。
- **指定材料副本**：从列表选择副本和一名培养角色。培养角色用于指南目标，战斗仍用当前出战三人。
- **按角色培养（自选项目）**：选择“当前三人”“指定一人”或“指定三人”，再勾选刷取项目。所有目标共用选择，默认只选声骸；可多选突破、武器/技能、周本、角色经验、武器经验、贝币。只选声骸时读取当前培养角色合鸣图鉴中的套装名，再与无音区筛选栏核对；不刷材料，推荐不明则跳过。现场读取实际队伍与需求，拥有情况以游戏核验为准。

副本和角色不需要输入名称。未核实中文培养名的角色暂不提供选项。要改出战队伍，请在游戏编队后重新读取；培养下拉框不会改队。

## 消费限制与停止

默认不领奖，首次建议关闭领奖测试1场。

| 控件 | 含义 |
| --- | --- |
| 场数 / 奖励份数 | 不领奖时是最多战斗场数；领奖时还受份数限制，双倍算2份 |
| 波片上限 | 本轮消费总量；材料本通常每份40、Boss/无音区通常60，仍以现场核对为准 |
| 储备上限 | 默认0；若游戏一次提取整额，超出本轮额度则停止 |
| 溶剂上限 | 默认0；结合历史账本计算累计授权，不继承维护者个人额度 |

关闭领奖强制全部消费额度为0；自选培养项目支持不领奖练习。场数与消费额度由所有角色、所有勾选项目共用，任一额度到限即结束，不使用星声。已完成的限额实测见下文；其他角色与队列组合仍需独立验收，详见[更新说明](cultivation-scope-2026-11-04.md)。

底部操作始终可见。暂停/继续释放按键，但**不暂停游戏敌人**。打完本场停止会完成本场战后流程，后续不再开打；已开启领奖时本场仍可能按原预算领奖。立即停止中断输入并保留未核对记录。关闭面板会先停止控制器。单轮最长10分钟活动时间，暂停不计控制器时限，游戏状态仍会变化。

## 报错与提交报告

1. 先停止，保留游戏现场和原安装。不要重复领奖或删除保护文件解锁。
2. 普通进场/战斗失败且没有待核对消费时，可点**返回并治疗**。未知页面仍会停止，不保证所有异常都自动恢复。
3. 在**记录与问题报告**选择失败那次运行，填复现步骤、预期/实际表现，点**导出脱敏诊断包**。导出不上传、不解除消费保护。
4. 点**打开GitHub反馈页**，填写版本、芯片/系统、语言/尺寸、任务、副本与队伍，把ZIP拖到附件区，检查后自行提交。
5. 额外截图先遮住UID、账号名和个人信息；不要提交整个配置目录或未经检查的原始日志、录屏。

| 本地位置 | 保存内容 |
| --- | --- |
| logs/desktop-runs | 每次完整终端日志、结果JSON、停止请求标记 |
| logs/battle-triggers | 失败决定帧、HP来源帧、判定JSON（有图像时） |
| logs/combat-recordings/运行编号 | GUI任务控制器存帧；当前运行最多最近600帧，约2分钟，不另开采集器 |
| configs/macos-desktop | 个人偏好、账本、队列检查点，不随发布包提供 |

脱敏ZIP默认包含版本/源码标识、系统/Python/依赖、所选任务结果、消费状态及最多160行/64KiB的脱敏日志尾部。排除原始截图、完整日志和账号配置。自动脱敏不是万能，提交前仍需查看附件；复现文字不要填UID、账号、密码或令牌。

安装/依赖错误：先诊断，不直接改锁定依赖。权限/捕获错误：核对宿主权限、前台和画面尺寸。进场超时：保留记录，不手动连点。血量/锁定/胜利未确认：属于未通过，不作为领奖依据。消费待核对：保留原结算与记录交维护者核对，没有一键删除保护。

## 更新与验证范围

更新解压到新目录并保留旧安装、账本，本版不自动迁移历史；有待核对消费时不要迁移或抹去旧记录。卸载先停止控制器、备份需要的记录，再删除对应解压目录和启动器；不修改游戏文件。

本次源码修复经过离线、模拟输入、GUI与安装验证；限额实测以玄翎／弗洛洛／穗穗为心刷取衔梦照世之心，分别完成沉心域、烬心域领奖。治疗上限变化的分支通过离线回归，最终胜利未触发紧急治疗；独立 App 只验证启动与离线组件，不追加实机消费。周本、部分Boss、同名地区入口、野外聚落、多机器和其他显示条件仍需独立验收，不能报告全关卡稳定。
