# macOS 内测包交付记录

版本：0.1.0-beta.1。初稿：2026-10-30；屏幕适配补充：2026-10-31，墨尔本。

## 本次交付

- 新默认面板分为开始刷取、运行记录、异常与恢复、首次设置四页。
  任务目标、资源额度、实际队伍和运行结果集中显示；底部开始/暂停/停止不随内容滚动消失。
- 面板以独立子进程调用现有 `ultrawide_trial.py`，继续共用 `MacSession`、消费预算和保护记录。
  面板启动不创建游戏控制器；只有显式操作才连接。预览模式不连接游戏也不写用户配置。
- 真正新安装可显式建立零账本。已有历史、损坏账本、初始化中断或待核对消费都不能借初始化清零。
- 每次新面板开刷均现场核对三人身份、等级、HP和索拉等级。未知和低练度队伍停止；
  首批只把已验证的玄翎队/索拉8/玄幽东岳列为优先内测，其他组合明确标为实验性。
- 新声骸消费保存账本基线与唯一记账标记。两帧新鲜只读结果可恢复核对，
  账本写入后或检查点写入后中断都不会重复计费。无法证明的情况保留保护。
- 发布器按白名单导出当前两仓库实际源码，包括未提交修改；不把Git HEAD当作实际运行版。
  每个导出文件有SHA256，manifest还保存两个基准提交及整个源码快照标识。
- 不导出个人配置、账本、日志、虚拟环境或测试截图。模板源图只保留标注识别区域，
  保持画布坐标和ROI像素一致；小图标与模型按需保留。
- 固定Python3.13/macOS依赖；框架构建版本改用本地VERSION，不再联网推算版本号。
- 屏幕适配补充：采集目标同时记录窗口ID、PID、位置、尺寸、显示器ID与像素缩放。
  鸣潮任务中画面几何改变会停止本轮，并在面板说明原因；旧坐标不能继续输入，释放按键仍可执行。
  开始时不支持的画面尺寸/比例保留完整错误，不再只显示启动超时。
  同时修复窗口化备用截图的标题栏Y坐标换算及前台窗口选择。

## 验证与边界

本轮软件交付工作不控制游戏、不领奖、不补给。
新UI、预检、恢复及发布检查使用临时配置、保存帧和模拟输入。
此前实战验证及消耗另见 `echo-stability-2026-10-30.md`，不把此前实战说成新GUI已实机验收。

模板导出验证：51张源图，1920×1080、3024×1898、3440×1440各270个模板的识别区域
坐标与像素逐项一致。原日志：`logs/beta-template-export-validation-20261030.log`。
新UI在离屏Qt中检查四页，以及最小窗口下操作按钮可见性。
消费恢复覆盖错误/过期画面、不同波片读数、其他待核对消费、以及记账/检查点中断后的重试。

这次仍是可安装的源码内测包。未提供签名、公证或自带Python的`.app`。
另一台Mac和新账号实机、真实暂停/继续/关闭、新UI整条刷取链、预检菜单读取及旧异常迁移
仍需按用户指南验收。材料/补给异常不提供自动清理入口。

## 重建

在项目根目录运行：

```sh
PYTHONPATH=../ok-script:. ../ok-script/.venv313/bin/python scripts/build_macos_beta.py \
  --output dist/ok-ww-macos-beta-20261031 --version 0.1.0-beta.1
```

输出目录和ZIP不可覆盖已存在文件；每次重新构建使用新目录，避免替换用户已开始使用的包。
实际交付内容以包根 `release-manifest.json` 为准。
